# 💬 Live Chat App using ASP.NET Core & SignalR

A real-time chat application built with **ASP.NET Core MVC and SignalR**.  
Users can send and receive messages instantly without refreshing the page.

---

## 🚀 Features

- 🟢 Real-time messaging using SignalR
- 👤 User name-based chat
- 🔄 No page reloads – instant communication
- 🎨 Modern and responsive UI
- 📡 SignalR Hub integrated with frontend JS
- 🛠 ASP.NET Core MVC project structure

---

## 🏗 Tech Stack

| Technology | Usage |
|------------|--------|
| **ASP.NET Core 6 MVC** | Backend framework |
| **SignalR** | Real-time WebSocket communication |
| **C#** | Server-side language |
| **JavaScript** | Frontend chat handling |
| **HTML/CSS** | UI Design |
| **Bootstrap & Custom CSS** | Styling |
| **Visual Studio** | IDE (optional) |
